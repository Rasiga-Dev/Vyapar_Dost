VYAPAR DOST - PYTHON FLASK VERSION

1. Install Python 3.10 or newer from https://www.python.org/downloads/ and select Add Python to PATH.
2. Open .env with Notepad. Replace paste_your_api_key_here with your OpenAI API key from https://platform.openai.com/api-keys
   OpenAI API billing is separate from ChatGPT Plus.
3. Double-click start_windows.bat (or run: py -m pip install -r requirements.txt ; py app.py).
4. Open http://127.0.0.1:5000 in Chrome or Edge.
5. Allow microphone permission. Speech recognition and speech output depend on browser support and installed voices.
6. Keep the terminal window open while using the app. Press Ctrl+C to stop.

Never share your .env file or API key. An internet connection is needed for AI responses.
The calculator works locally even without the AI API key.
The interface has 13 languages; browser speech availability differs by language and platform.
